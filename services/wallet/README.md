# wallet

Обычный микросервис кошельков со своей базой данных. Роль базы играет map в памяти процесса: сервис и хранилище — одно целое.

Пока пользователей мало, хватает одного экземпляра. Когда данные и нагрузка перестают в него помещаться, сервис нужно шардировать: разложить пользователей по нескольким экземплярам.

Сам сервис про шардирование ничего не знает: хранит тех пользователей, которых ему прислали. Кого куда отправить и как переносить данные при добавлении ноды, решает роутер.

## Сущности

- **Пользователь** — `user_id` и его кошельки. Единица шардирования: все кошельки пользователя лежат на одной ноде.
- **Кошелёк** — валюта (`USD`) и баланс в минимальных единицах валюты: центах, копейках, иенах.
- **Нода** — экземпляр сервиса со своим именем `node_id`, например `wallet-3`. Сколько пользователей ей достанется, решает роутер: вес ноды задаётся в топологии.
- **Версия топологии** — номер конфигурации кластера. Роутер передаёт его в `X-Topology-Version`, нода отклоняет запросы со старой версией (409). Без заголовка запрос проходит, если нода не в строгом режиме.

## Ручки

| Ручка | Что делает |
| --- | --- |
| `GET /wallet/{userID}` | кошельки пользователя, 404 если его нет |
| `POST /wallet/{userID}/deposit` | пополнение `{"currency":"USD","amount":100}`, создаёт пользователя и кошелёк, если их нет |
| `POST /wallet/{userID}/withdraw` | списание, нельзя уйти в минус; кошелёк не создаёт |
| `GET /export` | все пользователи ноды, по одному JSON на строку |
| `POST /import` | принимает пользователей в том же формате, заменяет существующих |
| `POST /evict` | удаляет пачку пользователей по списку `{"user_ids": [...]}` |
| `POST /fence` | запоминает версию топологии из заголовка; `{"strict": true}` — отклонять и запросы без версии |
| `GET /stats` | имя ноды, последняя версия топологии, строгий режим, сколько пользователей и кошельков |
| `GET /healthz` | жив ли процесс |
| `GET /metrics` | метрики Prometheus |

`/export` и `/import` нужны роутеру для переноса пользователей между нодами.

Swagger с описанием всех ручек — на `/swagger/`, корень `/` ведёт туда же.

## Запуск

Одна нода на `:8080`, из папки `services/wallet`:

```bash
task run
```

Загрузить в неё пользователей из снапшота, из корня репозитория:

```bash
task data
task import
```

Кластер из пяти нод на портах 9001–9005 поднимается сценариями из `scenarios/`.

Параметры в `config.yaml`, их можно перекрыть переменными окружения `ADDR` и `NODE_ID`.

## Попробовать

```bash
curl -X POST localhost:8080/wallet/42/deposit -d '{"currency":"USD","amount":150}'
curl -X POST localhost:8080/wallet/42/withdraw -d '{"currency":"USD","amount":50}'
curl localhost:8080/wallet/42
curl localhost:8080/stats
```
