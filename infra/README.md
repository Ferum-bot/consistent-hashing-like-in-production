# infra

Всё, что крутится вокруг сервисов: сбор метрик и дашборд.

| Папка | Что внутри |
| --- | --- |
| `prometheus/` | что и как часто собирать: все wallet, роутеры и loadgen раз в 5 секунд |
| `grafana/` | подключение к Prometheus и дашборд «Кластер кошельков» |

Отдельно infra не поднимается: её подключает каждый сценарий из `scenarios/`.

## Дашборд

Дашборд хранится в репозитории: `grafana/dashboards/cluster.json`. Grafana подхватывает его при старте, поэтому после клона и `task scenario` он уже открыт на главной странице, ничего импортировать не нужно.

Этот файл — единственный источник правды. Grafana хранит свою базу внутри контейнера, и всё, что сохранено только в интерфейсе, пропадёт при пересоздании контейнера. Чтобы поменять дашборд:

1. отредактировать панели в Grafana;
2. Export → Export as JSON, переключатель «Export the dashboard to use in another instance» оставить выключенным;
3. заменить содержимое `grafana/dashboards/cluster.json`.

Grafana перечитывает файл сама, перезапуск не нужен.

## Порты

Всё, что поднимает стенд в Docker:

| Что | Порт на машине | Что там открыть | В каких сценариях |
| --- | --- | --- | --- |
| wallet-1 | 9001 | Swagger по корню, `/stats`, `/metrics` | во всех |
| wallet-2 … wallet-5 | 9002 … 9005 | то же | в кластерных |
| router-1, router-2 | 8081, 8082 | Swagger по корню, `/locate/{id}`, `/topology`, `/metrics` | в кластерных |
| loadgen | 8090 | Swagger по корню, `/config`, `/ledger`, `/metrics` | во всех |
| Grafana | 3000 | дашборд открывается сразу, логин не нужен | во всех |
| Prometheus | 9090 | запросы к метрикам и список целей в Status → Targets | во всех |

Внутри Docker все сервисы слушают `8080` и обращаются друг к другу по именам: `http://wallet-3:8080`, `http://router-1:8080`.

У нод и роутеров в сети стенда фиксированные адреса: wallet-1 … wallet-5 — `172.28.0.11` … `172.28.0.15`, роутеры — `172.28.0.21` и `172.28.0.22`, остальным сервисам адреса выдаются из `172.28.0.128/25`. Без этого `task reset` перезапускает ноды, Docker раздаёт им адреса заново, и Prometheus или роутер, переподключившись в этот момент, может остаться с соединением к чужой ноде.

## Без Docker

Если запускать сервис локально через `task run` в его папке, он слушает `:8080` из своего `config.yaml`. Чтобы поднять рядом несколько сервисов, поменяй порт через переменную окружения:

```bash
ADDR=:8085 task run
```
